
# Student Management System

A simple, interactive, and console-based (or GUI-based) **Student Management System** developed in Python. This project is designed to easily manage student records, making it efficient to add, view, update, and delete student details.

---

## 🚀 Features

* **Add Student:** Easily enroll new students with their details (ID, Name, Roll Number, Course, etc.).
* **View Students:** Display a list of all currently registered students.
* **Search Student:** Look up a specific student using their unique ID or Roll Number.
* **Update Student:** Modify existing information for a student.
* **Delete Student:** Remove a student's record from the system.
